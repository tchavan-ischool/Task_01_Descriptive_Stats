# Findings — Facebook Political Advertising Dataset

## Scope and structure
The provided file `fb_ads_president_scored_anon.csv` contains **246,745 advertising records across 40 columns**. It has **246,745 distinct `ad_id` values**, **4,475 distinct `page_id` values**, and **4,546 distinct `page_name` values**. This difference between page identifiers and names cautions against treating displayed names as unique organizations. The file includes creation and delivery dates, page and byline information, platform information, ranges for estimated audience, impressions and spend, and a set of scored message and topic indicators. The observed creation dates span **July 6, 2021 to November 5, 2024**, so the file should not be described as containing only ads created in calendar year 2024.

## Completeness and interpretation
The clearest missingness occurs in `ad_delivery_stop_time` (**2,159 missing values**), `bylines` (**1,009**), and `estimated_audience_size` (**579**). These are not zeros: a missing stop date, for example, should not be interpreted as a campaign ending immediately. Other columns may contain coded or nonstandard values that are present but still require interpretation. Before analyzing spending, a researcher must inspect the actual data representation. `spend` and `impressions` are stored as strings containing lower and upper bounds rather than exact transaction-level measurements. A single precise spending or impression figure cannot be read directly from these fields. Some impression ranges also contain unusual bounds, which requires validation before aggregating estimates. The baseline scripts therefore summarize these fields as categorical values instead of quietly manufacturing exact amounts.

## Concentration and message patterns
There are **3,790 distinct non-null byline values**. The most frequently occurring byline is `HARRIS FOR PRESIDENT` with **49,788 records**, or approximately **20.18%** of all records. This is a count of ad records associated with a byline, not a share of dollars spent or people reached. It also does not establish that the same byline was responsible for all ad creative, that an individual person saw these ads, or that ad exposure changed anyone's views. The dataset contains multiple types of advertising organizations, and record counts should be separated from organizational identity and spending magnitude.

The dataset includes coded indicators for message characteristics and topics. For example, the `illuminating_msg_type_advocacy` indicator is 1 in **135,372 records**, `illuminating_msg_type_issue` in **94,170**, and `illuminating_msg_type_attack` in **67,079**. These labels are not necessarily mutually exclusive: summing them does not yield a unique total of ads. Among topic indicators, `illuminating_topic_economy` appears in **30,133 records**, `illuminating_topic_health` in **26,942**, and `illuminating_topic_social_and_cultural` in **26,115**. These are counts of supplied labels, not independently verified assessments of the ads' full meaning.

## What the statistics do—and do not—show
The data makes it possible to describe how advertising records are distributed across pages, bylines, time fields, and message classifications. However, frequency alone does not demonstrate effectiveness. It would be inappropriate to infer voter behavior, audience persuasion, or causal impact from these descriptive summaries. Even a comparison of spend requires explicit handling of ranges, currency differences, missingness, and potentially inconsistent bounds. This exercise therefore demonstrates why a researcher should inspect schema and quality before interpreting apparently straightforward totals.

## Conclusion
The strongest finding is methodological as well as substantive: a large political-ad dataset contains meaningful organizational and message patterns, but reliable conclusions depend on understanding each field's unit and limitations. A reproducible analysis must distinguish unique identifiers from display names, missingness from zero, classification flags from exclusive categories, and estimated ranges from observed amounts. The two independent implementations provide a useful cross-check of descriptive calculations while leaving substantive interpretation to transparent, appropriately limited research judgment.
